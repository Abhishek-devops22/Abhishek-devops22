## 🚀 Projects

### [AI-Native Kubernetes Observability Platform](https://github.com/Abhishek-devops22/ai-observability-platform)
Production-grade observability platform combining Kubernetes, OpenTelemetry, Prometheus, Loki, and Tempo with an AI layer for root cause analysis, anomaly detection, and automated remediation. Includes a full deployment stack with Terraform, Kubernetes manifests, and GitHub Actions automation.
**Stack:** Kubernetes · Terraform · OpenTelemetry · Prometheus · Loki · Tempo · Grafana · MCP Server · PyTorch/Scikit-learn · GitHub Actions

### [AWS Terraform Automation](https://github.com/Abhishek-devops22/aws_terraform_automation)
Infrastructure-as-Code project that fully automates provisioning of an AWS network environment — VPC, subnet, internet gateway, route table, and security groups — and deploys an EC2 instance running Nginx in a containerized setup.
**Stack:** Terraform · AWS (VPC, EC2, Security Groups) · Docker · Nginx
